PERCEPTION AND DECISION CORE
2.1.1

INTRODUCTION.

The agent plays POKEMON BLUE by understanding each room, not by replaying scripts. It sees every room twice: the RAM reader reports it as a 10 by 9 tile grid from emulator memory, and a vision model reports the same screen as a character grid. The two pictures are compared cell by cell every frame; every disagreement is a finding (figure 2.1-1).

2.1.2

FUNCTIONAL DESCRIPTION.

Each cycle the bridge returns one frame and the RAM reader returns the room tile grid. The vision model describes the same frame as a character grid using the floor, wall, grass, water, doorway and person symbols. The verdict compares the grids cell by cell and reports every disagreement as a finding. JEV decides each cycle; below 0.50 confidence or above 0.40 ambiguity it hands the state, not the action, to the reasoning model (figure 2.1-2).

2.1.2.1

Two Grids, One Law.

The RAM reader renders 10 columns by 9 rows with the facing arrow at row 3; the vision module declares 9 by 9 with the player at row 4. Until one definition is shared, every verdict row is one row high and the comparison is wrong by construction (requirement R-001, row VISION-GRID-UNIFY).
