MONITORING AND RELEASE
8.1.1

INTRODUCTION.

The agent is observed from four directions: Prometheus metrics on the dashboard, a node_exporter record from the cron lane, narration keys in DuckBrain, and the scheduler's own tick and cost ledger (figure 8.1-1).

8.1.2

FUNCTIONAL DESCRIPTION.

Version 1.1.0 is the first published release: the tag fires its own CI, the wheel installs with the source package intact, and the version surfaces agree. Cuts require owner authorisation; the releng lane audits readiness each sweep.

8.1.2.1

Cost Truth.

Costs are counted from the scheduler's session ledger by base URL and model, never from a billing label that a gateway restart can restamp.

8.1.2.2

What The Numbers Must Never Do.

A cost read from a billing label lies after a gateway restart; count by base URL and session ledger instead. A lazy all-floor answer must never win a cell-match metric: score the cells that carry meaning, the walls and doors and sprites.
