The three gaps between us and L2

Gap 1 · movement

Oak's Lab wander (FM#23)

The agent moves but never targets the lab exit door (tileset-5 block 0x04, bottom-center, map 40). The rival battle lives at that door — no exit targeting, no organic battle, ever. Door-aware steering exists for bedroom/house/Pallet; map 40 was never added.

→ R2: add map-40 door targeting to _suggested_map_action(). One tick. Unblocks everything.

Gap 2 · intelligence

Memory starvation

The READ→NOTE→ACT channel is built and smoke-proven (the agent set its own goal from Oak's dialog in testing) — but every run since has logged zero memory events: 20-cycle checkpoint runs boot past the narrative that gives it something to note. The Alice research was blunt: memory across attempts was the single biggest lever in the video.

→ R3: exercise memory inside the 80-cycle narrative shape + persist /goals/current across runs.

Gap 3 · measurement

The instrument measures L0

E2E-001 fires 20-cycle runs and gates on exit-0 / leak / lock-rate — pipeline proof, not progress. The same map distribution passed green for 5+ straight windows. We re-proved L0 for weeks and called it advancement.

→ R4: E2E-001 becomes an 80-cycle narrative run scored on the L2 gate; 20-cycle demoted to smoke.

L2 acceptance gate

One run: --boot-state data/boot.state --cycles 80 (NO battle checkpoint), fresh run-id, live key. The gate passes when ALL of:

  • Agent writes ≥1 note or goal itself (memory_note / memory_goal in the jsonl, visible in DuckBrain)
  • Starter picked (deterministic branch allowed — an L1 assist)
  • battle_start → battle_end organically — battle fires from gameplay, not a battle-start checkpoint
  • Map progression 40 → 11 (Route 1) at any point post-battle
  • Run survives the 4 GB cap, 0 API failures
  • Review page + replay video delivered for Bane's screenshot review

Gate must pass twice (run-variance rule). Honest caveat carried: the deterministic starter branch and battle guardrails are assists — allowed at L2, tightened at L3. Key rotation (R6) is a Bane action; no run after 09-08 on the dead key counts as milestone evidence.
